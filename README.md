# deepseek-v4-hybrid-attention-from-scratch
Build the attention stack that lets DeepSeek-V4 run million-token contexts, in PyTorch, from the technical report's equations. Start with the token-level compressor that folds every m tokens into one KV entry with overlapping softmax weights and learnable positional biases, and the per-head RMSNorm the report applies to queries and KV entries.…
